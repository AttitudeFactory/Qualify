# Resources



## Required Actions Dashboard

The required actions dashboard aggregates all incomplete required actions into a single view, providing app administrators with enhanced visibility into requirements across the portfolio they manage - and ultimately helping prevent missed tasks and timelines.

Required actions dashboard will be available to most app administrators in April 2024. Only app administrators can use the required actions dashboard.

Users with partial-access app roles (e.g. developer, tester, etc.) will not be able to access the required actions dashboard at this point in time.

## Self-guided Video Tutorials

These 3-5 minute videos aim to help developers more easily navigate our processes from app creation, onboarding and app review, to more detailed requirements of our annual responsible initiatives checks, like the Data Protection Assessment security requirements, creating a privacy policy and creating screencasts for ongoing reviews.

The videos are embedded in relevant sections of the developer documentation guides, but you can also find all of them [here](https://developers.facebook.com/m/developer-tutorials/).
