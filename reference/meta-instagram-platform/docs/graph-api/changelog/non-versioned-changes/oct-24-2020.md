# October 24, 2020

## Legacy oEmbed Deprecation

### Facebook

The following legacy Facebook oEmbed endpoints have been deprecated. They have been replaced with [new Facebook oEmbed endpoints](/docs/plugins/oembed).

* `GET https://www.facebook.com/plugins/post/oembed.json/?url={content-url}`
* `GET https://www.facebook.com/plugins/video/oembed.json/?url={content-url}`

### Instagram

The following legacy Instagram oEmbed endpoints have been deprecated. They have been replaced with [new Instagram oEmbed endpoints](/docs/instagram/oembed).

* `GET https://api.instagram.com/oembed`
* `GET https://api.instagram.com/p/{post-url}/media`

## User Picture

* [`GET /user/picture`](/docs/graph-api/reference/user/picture#Reading) now requires an access token if querying a User ID (UID). Querying an App-Scoped User ID still does not require an access token.
