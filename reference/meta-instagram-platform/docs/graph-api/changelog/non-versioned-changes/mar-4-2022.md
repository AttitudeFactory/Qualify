# March 4, 2022

Out-of-cycle changes.

## Marketing API

In compliance with recent U.S. sanctions, starting February 25, 2022, we are removing the ability to geo-target regions, cities, addresses or zip codes within Luhansk and Donetsk, either for inclusion or exclusion.

All active or paused campaigns that geo-target these regions will be paused by March 4, 2022.

This change affects the following endpoints when creating ads:

* `POST /{ad-account-id}/adsets`
* `POST /{adset-id}`
