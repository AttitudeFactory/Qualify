# September 16, 2020

## User Picture

* [`GET /{user-id}/picture`](/docs/graph-api/reference/user/picture) requests made by apps in [Development mode](/docs/apps#development-mode) using either (1) a [Client access token](/docs/facebook-login/access-tokens/#clienttokens) or (2) tokenless requests on an App-Scoped User ID will receive a silhouette image instead of the app user's profile image in response.
* [`GET /{user-id}/picture`](/docs/graph-api/reference/user/picture) tokenless requests on App-Scoped User IDs made by apps that are [inactive](/docs/apps/#inactive-apps) or that have not completed [Data Use Checkup](/docs/apps/certifying_data_use) will receive an error code in response.
