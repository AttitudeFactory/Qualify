# February 7, 2018

## Removed Targeting Availability for 'Interested In' in Ads

As of February 7, 2018, we've removed “Interested in” targeting, which applies to all advertisers who use or have used 'Interested in Men', 'Interested in Women', 'Interested in Men and Women', or 'Interested in Unspecified' for targeting options. [Learn more](https://developers.facebook.com/ads/blog/post/2018/02/27/targeting-availability-interestedin/)
