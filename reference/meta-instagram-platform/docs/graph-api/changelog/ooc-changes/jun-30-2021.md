## Instagram Basic Display API

#### Private Account Access Tokens

*Applies to all versions.*

[Long-lived access tokens](/docs/instagram-basic-display-api/guides/long-lived-access-tokens) for private Instagram accounts can now be [refreshed](/docs/instagram-basic-display-api/guides/long-lived-access-tokens#refresh-a-long-lived-token). In addition, [permissions](/docs/instagram-basic-display-api/overview#permissions) granted to apps by app users with private accounts are now valid for 90 days.
