### Parameters

This endpoint doesn't have any parameters.

### Fields

| Field | Description |
| --- | --- |
| `id`  numeric string | The ID of the proposal |
| `acceptance_status`  enum | Indicate whether it was accepted or rejected only meaningful when the proposal is not pending  [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `category`  string | The category of the proposed change  [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `upcoming_change_info`  [PageUpcomingChange](https://developers.facebook.com/docs/graph-api/reference/page-upcoming-change/) | The upcoming change info of this proposal if the proposal will be automatically accepted |
