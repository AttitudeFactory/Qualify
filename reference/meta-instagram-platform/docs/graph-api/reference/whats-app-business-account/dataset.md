# Whats App Business Account Dataset

## Creating

You can make a POST request to `dataset` edge from the following paths:

* [`/{whats_app_business_account_id}/dataset`](/docs/graph-api/reference/whats-app-business-account/dataset/)

When posting to this edge, no Graph object will be created.
