# Recommendation

Represents a recommendation on a [Page](/docs/graph-api/reference/page).

This endpoint cannot be queried directly. Instead, use the [GET /<PAGE\_ID>/ratings](/docs/graph-api/reference/page/ratings/) endpoint to get a list of recommendations on a Page.

## Reading

This field is deprecated for v22.0 and future versions. Attempting to query an edge or field that returns a recommendation using v22.0 or later will return error code `12`.

### New Page Experience

This endpoint is supported for [New Page Experience](/docs/pages/new-pages-experience/).

### Parameters

This endpoint doesn't have any parameters.

### Fields

| Field | Description |
| --- | --- |
| `created_time`  datetime | When the reviewer rated this object  [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `has_rating`  bool | Was a rating included? (1-5 stars) |
| `has_review`  bool | Was there text in the rating? |
| `open_graph_story`  SingleRecommendationStory | Story generated by the rating/recommendation action |
| `rating`  int32 | Rating (1-5 stars)  [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `recommendation_type`  string | Whether or not this recommendation was "positive" or "negative"  [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `review_text`  string | Review text included in the review  [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `reviewer`  [User](https://developers.facebook.com/docs/graph-api/reference/user/) | Information about the author of a recommendation/review  [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
