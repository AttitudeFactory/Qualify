### Parameters

This endpoint doesn't have any parameters.

### Fields

| Field | Description |
| --- | --- |
| `excluded`  bool | Indicates whether the location was excluded or included in ad targeting. A return value of “true” indicates exclusion from targeting.  [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `name`  string | The name of the location targeted by the ad.  [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `num_obfuscated`  int32 | Indicates the number of smaller locations that the advertiser originally targeted which have been aggregated into the returned location.  [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
| `type`  string | The type of location targeted (“country”, “region”, “postal code”, “city”).  [Default](https://developers.facebook.com/docs/graph-api/using-graph-api/#fields) |
