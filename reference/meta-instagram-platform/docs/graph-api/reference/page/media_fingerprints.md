# Page Media Fingerprints

## Reading

Fingerprint files that have been uploaded to a Page.

### New Page Experience

This endpoint is supported for [New Page Experience](/docs/pages/new-pages-experience/).

### Parameters

| Parameter | Description |
| --- | --- |
|  |  |
| --- | --- |
| `universal_content_id`  string | A custom ID set by the fingerprint owner. |

### Fields

Reading from this edge will return a JSON formatted result:

```
{
    "data": [],
    "paging": {}
}
```

#### `data`

A list of [MediaFingerprint](/docs/graph-api/reference/media-fingerprint/) nodes.

#### `paging`

For more details about pagination, see the [Graph API guide](/docs/graph-api/using-graph-api/#paging).

### Error Codes

| Error | Description |
| --- | --- |
| 200 | Permissions error |
