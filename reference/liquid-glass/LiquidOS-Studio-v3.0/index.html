Documentation

LiquidOS is now structured as a small core design system, a Studio app, and independent demos. The core can be dropped into an existing site without bringing the showcase with it.

Quick start

Load the foundation stylesheet, add the material classes, and optionally include the interaction runtime for ripples, sheen, dialogs, and utilities.

<link rel="stylesheet" href="assets/css/liquidos.css">

<article class="lq-glass lq-glass--liquid lq-panel">
  Your content
</article>

<script src="assets/js/liquidos.js"></script>
<link rel="stylesheet" href="assets/css/liquidos.css"> <article class="lq-glass lq-glass--liquid lq-panel">Your content</article> <script src="assets/js/liquidos.js"></script>

Core guarantees

The rebuild removes the fragile runtime assumptions found in the older packages.

  • No CDN dependency for layout, icons, fonts, charts, or interactions.
  • Every control includes visible focus treatment and semantic HTML.
  • Animations respond to reduced-motion preferences.
  • Shared tokens keep demos and components visually consistent.
  • Mobile layouts start at 320px without horizontal overflow.

Design tokens

Override these variables at :root, on a page wrapper, or on one component.

--lq-accent
--lq-accent-2
--lq-glass-alpha
--lq-bg
:root {
  --lq-accent: #8b7cff;
  --lq-accent-2: #51d7ff;
  --lq-blur: 24px;
  --lq-radius: 20px;
  --lq-glass-alpha: 0.075;
}
